# @parlajs/format-icu

ICU MessageFormat → MF2 data model, for [Parla](https://github.com/marcalexiei/parla)'s
compiler (`"format": "icu"`).

Supports placeholders, `plural` (`=N`, `offset`), `selectordinal`, `select`, `number`
(`::currency/EUR`, `percent`), `date`, `time` and `<tag>…</tag>`. Not `duration`.
