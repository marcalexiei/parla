# @parlajs/format-mf2

[MessageFormat 2](https://messageformat.unicode.org/) parsing and validation for
[Parla](https://github.com/marcalexiei/parla)'s compiler (`"format": "mf2"`).

Supports `:number`, `:integer`, `:currency`, `:percent`, `:unit`, `:date`, `:time`, `:datetime`,
`:string`, `.input`/`.local`, multi-selector `.match` and `{#tag}…{/tag}`.
