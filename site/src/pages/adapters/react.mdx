# `@parlajs/react`

<Badge>Framework adapter</Badge> `pnpm add @parlajs/react`

Requires React 19. Re-exports [`@parlajs/core`](/core/api), with rich text typed as `ReactNode`.

```tsx
import { createParla, ParlaProvider, useLocale, useParla, useParlaLoaded } from '@parlajs/react';

const parla = createParla({ catalog });

createRoot(root).render(
  <ParlaProvider parla={parla}>
    <Suspense fallback={null}>
      <App />
    </Suspense>
  </ParlaProvider>,
);
```

| Export                    |                                                                 |
| ------------------------- | --------------------------------------------------------------- |
| `createParla(options)`    | Core's, with rich text rendered as React nodes                  |
| `<ParlaProvider parla>`   | Puts the instance in context                                    |
| `useParla(list)`          | `{ t }`. Suspends until loaded; loaded namespaces never suspend |
| `useParlaLoaded(list)`    | `{ t }`, `undefined` until loaded. Never suspends               |
| `useLocale()`             | `{ locale, locales, setLocale }`; re-renders on switch          |
| `Translations<typeof ns>` | The type of `t`, with `ReactNode` rich text                     |

- A failed download reaches the nearest error boundary; a failed switch rejects `setLocale`.
- The hooks throw outside `<ParlaProvider>`.

## Loading

`useParla` suspends until its namespaces [load](/core/loading). `useParlaLoaded` never suspends: `t`
is `undefined` until then.

```tsx
function Cart() {
  const { t } = useParla([checkout]); // suspends until loaded
  return <h1>{t.checkout.title()}</h1>;
}

function CartBadge() {
  const { t } = useParlaLoaded([checkout]); // never suspends
  if (!t) return <span>…</span>;
  return <span>{t.checkout.title()}</span>;
}
```

Passing `t` to children: [Components and routes](/adapters/react-components).

## Switching locale

`setLocale` loads first, then [switches](/core/switching-locale) and re-renders: nothing suspends.

```tsx
const { locale, locales, setLocale } = useLocale();

<select value={locale} onChange={(e) => setLocale(e.target.value).catch(reportError)}>
  {locales.map((l) => (
    <option key={l}>{l}</option>
  ))}
</select>;
```

## Rich text

Each tag's callback returns a `ReactNode`:

```tsx
t.home.terms({ link: (c) => <a href="/terms">{c}</a> });

createParla({ catalog, markup: { strong: (c) => <strong>{c}</strong> } });
```
