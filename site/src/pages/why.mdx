# Why Parla

i18n libraries make you choose. Typed keys or typed params. Lazy loading or types that know what
loaded. ICU or something newer. Parla wants all of them, with one way to do each thing:

- every message is a typed function, params read from the message itself;
- `t` holds only the namespaces that loaded, so "not loaded yet" is a type error, not a blank string;
- one chunk per locale × namespace, and the bundler ships only what the app imports;
- ICU and MessageFormat 2, per namespace;
- `setLocale` loads first, then switches.

## Why it was built

Each library above gets part of this right; none does all of it. Parla types params from the message,
knows what loaded, splits per locale and namespace, and reads both ICU and MF2, at 2.7 kB.

Parla is built with the help of AI coding tools.
