# Namespaces

Each namespace in `parla.config.ts` compiles to `<outDir>/namespaces/<name>.js`, which exports it
under its name. Import it, and pass it:

```tsx
import { checkout } from './parla/namespaces/checkout.js';
import { common } from './parla/namespaces/common.js';

const { t } = useParla([checkout, common]);
t.checkout.title();
t.common.save();
```

The object is `{ name, load }`: one chunk loader per locale. Its `.d.ts` types every message.

| Because a namespace is an import  |                                                                         |
| --------------------------------- | ----------------------------------------------------------------------- |
| The bundler ships what you import | Nothing lists every namespace, so none ships by accident                |
| The types follow                  | `tsc` reads only the `.d.ts` of imported namespaces                     |
| Tooling follows                   | Tools such as [x18n](/reference/x18n) read which namespaces a file uses |
| A name does not type-check        | `useParla(['checkout'])` is an error                                    |

Import each namespace from its own module, never through a barrel: the bundler then splits exactly
those chunks.

## Names

A namespace's name is its module, its export, its key in `t` and its name at runtime. Make it an
identifier in your project's case, and map a file name that differs:

```ts
namespaces: { scopeAudit: { format: 'icu', path: 'locales/{locale}/scope_audit.json' } },
```

- A name that is no identifier (`foo-bar`) exports as `fooBar` while `t` keeps `foo-bar`; the build
  warns.
- Alias a clash with a local name as `<name>Namespace`: `import { user as userNamespace }`.
- Rename a namespace that clashes often, rather than prefixing every one.

## By name, from data

Keep a map:

```ts
const byName = { checkout, common };
await parla.load([byName[route.namespace]]);
```

A missed lookup passes `undefined`: `load` throws a `TypeError` naming it.

## All of them, in a test

A test that loads every namespace can glob them with Vite:

```ts
const all = Object.values(
  import.meta.glob<Record<string, Namespace>>('./parla/namespaces/*.js', { eager: true }),
).flatMap((mod) => Object.values(mod));
```
