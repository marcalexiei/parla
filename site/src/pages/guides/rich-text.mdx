# Rich text

:::code-group

```json [MF2]
{ "terms": "Accept the {#link}terms{/link}, {#strong}today{/strong}." }
```

```json [ICU]
{ "terms": "Accept the <link>terms</link>, <strong>today</strong>." }
```

:::

Each tag is a param: a function from its children to a node.

```tsx
t.home.terms({ link: (c) => <a href="/terms">{c}</a> });
```

<RichTextDemo />

The second line passes its own `strong`. The first leaves it out: `strong` is declared in the
config's `markup`, so the instance renders it.

```ts
// parla.config.ts
markup: ['strong'],

// the app
createParla({ catalog, markup: { strong: (c) => <strong>{c}</strong> } });
```

| Markup                  | Param                                |
| ----------------------- | ------------------------------------ |
| In the message          | Required: `link: (children) => Node` |
| Also in config `markup` | Optional; a call's own wins          |
| Self-closing, `{#br/}`  | Its callback gets empty children     |

## The node follows the instance

One namespace serves both a React app and, say, emails:

| Instance                            | `Node`      | `t.home.terms(…)` returns |
| ----------------------------------- | ----------- | ------------------------- |
| `createParla` from `@parlajs/react` | `ReactNode` | a `ReactNode`             |
| `createParla` from `@parlajs/core`  | `string`    | a `string`                |

Messages without markup return `string` in both, so either instance's `t` fits a component that
reads only those.

```ts
import { createParla } from '@parlajs/core';

const mail = createParla({ catalog, markup: { strong: (c) => `**${c}**` } });
const t = await mail.load([home]);
t.home.terms({ link: (c) => `[${c}](https://example.com/terms)` }); // a string
```

Another framework passes `wrapRich` to `@parlajs/core`'s `createParla` and types `Parla<Node>`.
