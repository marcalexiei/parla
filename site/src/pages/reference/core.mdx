# `@parlajs/core`

```ts
import { createParla, matchLocale } from '@parlajs/core';

import { catalog } from './parla/catalog.js';
import { checkout } from './parla/namespaces/checkout.js';

const parla = createParla({ catalog, locale: 'it' });
const t = await parla.load([checkout]);
t.checkout.cart.items({ count: 3 }); // "3 articoli"
```

## `createParla(options)`

| Option      |                                                             |
| ----------- | ----------------------------------------------------------- |
| `catalog`   | `catalog.js`, written by the build                          |
| `locale`    | The first locale; default the source locale                 |
| `functions` | Required, with every name the config's `functions` declares |
| `markup`    | Required, with every name the config's `markup` declares    |
| `wrapRich`  | Joins rich parts into one node; set by framework adapters   |

## `Parla<Node>`

| Member                | Type                                  |                                                                        |
| --------------------- | ------------------------------------- | ---------------------------------------------------------------------- |
| `locale`              | `Locale`                              | Current                                                                |
| `locales`             | `readonly Locale[]`                   | The catalog's                                                          |
| `load(list)`          | `Promise<Translations<NS, Node>>`     | See [Loading](/guides/loading)                                         |
| `loaded(list)`        | `Translations<NS, Node> \| undefined` | `t` if loaded for the current locale; never downloads                  |
| `setLocale(locale)`   | `Promise<void>`                       | Loads, then switches; see [Switching locale](/guides/switching-locale) |
| `subscribe(listener)` | `() => void`, to unsubscribe          | Called after each switch                                               |

`load` returns a promise carrying `status` and `value` once settled, which React's `use()` reads
without suspending.

## Functions and types

| Export                                                 |                                                          |
| ------------------------------------------------------ | -------------------------------------------------------- |
| `matchLocale(requested, supported, fallback)`          | Best supported locale from a preference list             |
| `Translations<typeof ns>`                              | The type of `t` for those namespaces; `Node` is `string` |
| `Namespace<Name, Kind, L>`                             | A namespace object: `{ name, load }`                     |
| `Catalog`                                              | `{ locales, sourceLocale }`                              |
| `Locale`                                               | The app's locales, once a catalog is built               |
| `Text`                                                 | A message without params or markup: `() => string`       |
| `MessageFunction`                                      | `(value, options, locale) => string`, for `functions`    |
| `LocaleRegistry`, `FunctionRegistry`, `MarkupRegistry` | Augmented by generated code; never by hand               |

Load one copy of `@parlajs/core`: a library depending on it makes it a `peerDependency`. Two copies
split locale state, and the second warns.
