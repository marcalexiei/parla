# `@parlajs/x18n-plugin`

Parla's plugin for [x18n](https://x18n.dev).

```sh
pnpm add -D @x18n/cli @parlajs/x18n-plugin
```

```ts
import parla from '@parlajs/x18n-plugin';
import { defineConfig } from '@x18n/cli';

export default defineConfig({
  sourceLocale: 'en',
  locales: ['en', 'it'],
  // x18n then names keys `checkout:cart.items`: with its default `.`, a dotted namespace blurs into the key.
  namespace: { separator: ':' },
  plugins: [parla()],
  usage: { include: ['src/**/*.{ts,tsx}'], exclude: ['src/parla/**'] },
});
```

x18n puts `namespace.separator` between namespace and key in the names it prints and queries. Parla's
keys, and even its namespaces (`admin_user.v2-beta`), may contain dots, so `:` keeps them apart.

## What it reads

|                   |                                                                                                |
| ----------------- | ---------------------------------------------------------------------------------------------- |
| Catalogs          | Each under the namespace its `parla.config.ts` gives it                                        |
| Usages            | `t.ns.key()` on a `t` from `useParla([ns])`, or a `{ t }: { t: Translations<typeof ns> }` prop |
| Templates         | In `.vue`, `.svelte` and `.astro`: the scripts, Astro's frontmatter and template expressions   |
| Params and markup | Parla's own ICU and MF2 parsers, with the config's `functions` and `markup`                    |
| Custom formats    | A namespace's messages through its own adapter, from the config's `formats`                    |
| Selects           | Branches that need different params are left to TypeScript, which checks each one              |

Template expressions are Vue's `{{ }}` and directives, and Svelte's and Astro's `{…}`, `{#if …}` and
`{@html …}`, so `{t.ns.key()}` in markup counts: add those extensions to `usage.include`.

A namespace counts only when imported from its `namespaces/{ns}.js`, as Parla writes it. A catalog
that is not JSON, read through its adapter's [`parseFile`](/reference/config#formats), needs an x18n
format for its extension too: x18n reads and writes it.

## Options

| Option    | Default                    |                                                         |
| --------- | -------------------------- | ------------------------------------------------------- |
| `callees` | `['useParla']`             | Hooks that take a list of namespaces and return `{ t }` |
| `configs` | every `**/parla.config.ts` | Configs to read, relative to x18n's root                |
