# `parla.config.ts`

Imported by Node itself, through its type stripping: no loader, no build step.

```ts
import { defineConfig } from '@parlajs/compiler';

export default defineConfig({
  locales: ['en', 'it', 'de'],
  sourceLocale: 'en',
  fallbacks: { de: ['en'] },
  outDir: 'src/parla',
  namespaces: { checkout: { format: 'mf2', path: 'locales/{locale}/checkout.json' } },
  functions: { capitalize: 'string' },
  markup: ['strong', 'br'],
});
```

| Option         | Type                                           | Default                                                |
| -------------- | ---------------------------------------------- | ------------------------------------------------------ |
| `locales`      | `string[]`: tags such as `en`, `pt-BR`         | `[sourceLocale]`                                       |
| `sourceLocale` | `string`, one of `locales`                     | `'en'`                                                 |
| `fallbacks`    | `Record<locale, locale[]>`                     | `{}`, see [Fallbacks](/guides/fallbacks)               |
| `outDir`       | Relative to the config                         | `'src/parla'`                                          |
| `namespaces`   | `Record<name, { format, path }>`               | `{}`                                                   |
| `functions`    | `Record<name, 'string' \| 'number' \| 'date'>` | `{}`                                                   |
| `markup`       | `string[]`: tags a call may leave out          | `[]`                                                   |
| `formats`      | `Record<name, FormatAdapter>`                  | `{}`; `icu` and `mf2` are built in                     |
| `runtime`      | Module the types import and augment            | `@parlajs/react` if a dependency, else `@parlajs/core` |

## `namespaces`

| Field    |                                                              |
| -------- | ------------------------------------------------------------ |
| `format` | `'icu'`, `'mf2'` or a key of `formats`                       |
| `path`   | Catalog path relative to the config, with a `{locale}` token |

A name is letters, digits, `_`, `-` or inner dots: it names files. Make it an identifier, see
[Names](/guides/namespaces#names).

A catalog is JSON, or whatever its format's [`parseFile`](#formats) reads: a message per key, or a
group of them.

## `functions`

Message functions beyond the built-in ones, by what their value is: it types the param.
`createParla({ functions })` must implement each. Built-in names (`number`, `date`, …) cannot be
redefined. See [Your own functions](/guides/formatting#your-own-functions).

## `markup`

Tags that `createParla({ markup })` renders, so a call may leave them out. See
[Rich text](/guides/rich-text).

## `formats`

Message syntaxes beyond `icu` and `mf2`. A `FormatAdapter` parses one message into the
[MF2 data model](https://messageformat.unicode.org/docs/reference/data-model/), which is all the
compiler reads; a namespace's `format` names one. The CLI, the Vite plugin and
[x18n](/reference/x18n) read it from here.

| `FormatAdapter` |                                                                                 |
| --------------- | ------------------------------------------------------------------------------- |
| `name`          | The adapter's name                                                              |
| `parse`         | `(source) => Model.Message`: one message into the MF2 data model                |
| `parseFile`     | Optional. `(text) => { key: message \| group }`, for catalogs that are not JSON |

Without `parseFile`, catalogs are read as JSON. With it, a namespace's catalogs can be `.po`, `.ftl`,
`.properties` or anything else; a `parseFile` that throws is an `invalid-resource` diagnostic for that
file.

```ts
import { defineConfig, type FormatAdapter } from '@parlajs/compiler';

// Plain-text messages in `key = message` lines.
const properties: FormatAdapter = {
  name: 'properties',
  parse: (source) => ({ type: 'message', declarations: [], pattern: [source] }),
  parseFile: (text) =>
    Object.fromEntries(
      text
        .trim()
        .split('\n')
        .map((line) => {
          const at = line.indexOf('=');
          if (at < 0) throw new Error(`no "=" in "${line}"`);
          return [line.slice(0, at).trim(), line.slice(at + 1).trim()];
        }),
    ),
};

export default defineConfig({
  formats: { properties },
  namespaces: { legal: { format: 'properties', path: 'locales/{locale}/legal.properties' } },
});
```
