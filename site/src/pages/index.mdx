Type-safe i18n: one API, per-locale lazy loading, ICU and MessageFormat 2.

New: [Introducing Parla](/blog/introducing-parla).

:::warning
Experimental (`0.0.0`), not on npm yet.
:::

```tsx
import { checkout } from './parla/namespaces/checkout.js';

const { t } = useParla([checkout]);

t.checkout.title(); // "Checkout"
t.checkout.cart.items({ count: 3 }); // "3 items"; count: number, required
t.checkout.terms({ link: (c) => <a href="/terms">{c}</a> });
```

## Why

- **Typed messages**: each message is a function, with params from the message.
- **Typed loading**: `t` has only the namespaces that loaded.
- **Namespaces are imports**: the bundler ships only what the app imports.
- **Lazy**: one chunk per locale and namespace.
- **No flash on switch**: `setLocale` loads first.
- **ICU and MF2**, per namespace.
- **Monorepos**: one package owns each namespace.

## Layers

```
catalogs                   JSON, or what a parseFile reads
 └▶ format adapter         ICU, MF2 or yours → MF2 data model
     └▶ compiler           build time → typed namespaces
         └▶ core           runtime: locale, loading, Intl
             └▶ framework adapter   React, or yours

tooling, beside them       x18n reads catalogs and usages
```

| Layer                                | Package                                      | Does                                     |
| ------------------------------------ | -------------------------------------------- | ---------------------------------------- |
| [Format adapter](/formats/icu)       | `@parlajs/format-icu`, `@parlajs/format-mf2` | Parses a syntax into the MF2 data model  |
| [Core](/core/cli)                    | `@parlajs/compiler`                          | Builds catalogs into typed namespaces    |
| [Core](/core/api)                    | `@parlajs/core`                              | Runtime: locale state, loading, `Intl`   |
| [Framework adapter](/adapters/react) | `@parlajs/react`                             | `ParlaProvider`, `useParla`, `useLocale` |
| [Tooling](/tooling/x18n)             | `@parlajs/x18n-plugin`                       | Reads catalogs and usages for x18n       |
